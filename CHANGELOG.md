# Changelog

All notable portfolio releases are documented in this file.

## [1.0.0] - 2026-08-30

### Added

- Reproducible Python Bronze-to-Silver-to-Gold pipeline.
- Automated cleaning, model, and integration tests.
- Versioned Silver and Gold data-quality summaries.
- SQL Server staging and typed analytics schemas.
- SQL model validation and reusable business analysis.
- Power BI semantic model with one fact table, seven dimensions, seven relationships, and 35 DAX measures.
- Five-page Power BI report with navigation, accessibility metadata, and verified screenshots.
- Private Power BI Service deployment.
- Portfolio README, data dictionary, case study, interview guide, and application content.
- Rendered PDF case study.

### Data integrity

- Preserved and disclosed negative temporal cycles rather than silently correcting them.
- Excluded customer names and email addresses from the public analytical model.
- Labeled time analysis as purchase-cohort analysis because ticket creation date is unavailable.
- Disclosed CSAT and valid-duration sample coverage.
