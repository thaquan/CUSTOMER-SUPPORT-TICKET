## Portfolio summary - approximately 100 words

This end-to-end analytics project transforms 8,469 customer-support tickets into a validated decision-support product. A Python/pandas pipeline cleans and tests the source, then builds a Gold star schema with one fact table and seven dimensions. SQL Server adds typed loading, constraints, 34 validation checks, and reusable business queries. The Power BI semantic model contains seven relationships and 35 explicit DAX measures across five accessible report pages. The analysis covers backlog, CSAT, resolution performance, support demand, and customer segments while explicitly disclosing survey coverage, missing ticket-created timestamps, 1,365 negative temporal cycles, and the difference between purchase-cohort associations and causal conclusions.

## LinkedIn post - English

I have completed an end-to-end Customer Support Analytics portfolio project using Python, SQL Server, dimensional modeling, DAX, and Power BI.

The project transforms 8,469 raw support tickets into a validated star schema and a five-page dashboard covering executive KPIs, operations, CSAT, resolution performance, and customer segments.

Highlights:

- 21 automated Python tests
- 34 SQL Server validation checks
- 1 fact table and 7 dimensions
- 35 explicit DAX measures
- 5 accessible Power BI pages
- Power BI Service deployment

One of the most important lessons was that analytical integrity matters as much as dashboard design. The source has no ticket-created timestamp and contains 1,365 negative temporal cycles, so I disclosed those limitations instead of silently correcting or over-interpreting them.
